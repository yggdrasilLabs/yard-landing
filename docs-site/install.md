add a tap.

{% include install-tabs.html %}

## Prebuilt binaries

Every release also attaches standalone binaries for macOS (Apple Silicon and
Intel) and Linux (x86_64 and ARM) on [GitHub Releases](https://github.com/sean-mca/yard/releases).
Download the one for your platform, make it executable, and put it on your
`PATH`.
